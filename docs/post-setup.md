# Post Setup

`ansible-playbook localhost.yml` の実行後に手動で行うセットアップ。

## Claude Code

```
curl -fsSL https://claude.ai/install.sh | bash
claude
```

`claude` コマンドを実行してログインする。

## VS Code — `code` コマンドの有効化

1. VS Code を開く
2. Command Palette (`Cmd+Shift+P`) を開く
3. `Shell Command: Install 'code' command in PATH` を実行

## Alfred — ライセンス設定

1. Alfred を起動
2. Powerpack ライセンスを入力して有効化
